# 交易页

页面在 `/curve/`。人在币安 App 里确认。网页连上普通插件钱包 ≠ Agent 登录。资格只认链上 `msg.sender`。

注册表 `0x60B9262456dE011F7d15a54CdD8c48bAaa8B022F`。工厂、曲线和池的地址在 `deploy/book.json`。地址空着时，交易面板写「尚未接入现网」。面板上的数是发行常量，不是一笔已经发生的交易。

## 走完一次

1. 顶上选「铸」。只出现枚数。右栏是报价：你付、你得、单价、手续费。地址还空着时，主按钮写「尚未接入现网」，报价用「—」。
2. 地址接上之后，枚数保持 1，点「铸造」。右栏写出要付的 BNB。预览用人话说明这一笔。
3. 在币安 App 里确认。拒绝则没有交易。成功后剩余铸额减少，并且锁住。
4. 再选「卖」，点「卖回」。卖回不恢复铸额。
5. 要看池价：再铸 1 枚，然后选「入」（枚数 1，BNB 0.01）。加入之后池价和赎回价会同时出现，而且不是同一个数。然后可以选「换」或「出」。

官方配对：把币安给出的 `urlForWeb` 原样贴上，在新窗口打开。不要改其中的字，不要嵌 iframe。拒绝 `wc:`。

## 失败时看什么

| 你看到的 | 含义 | 下一步 |
| --- | --- | --- |
| 这个地址没有 Agent ID | 付款人在注册表上余额为 0 | 在币安 App 里领取。本页不代领 |
| 句柄是空的 | 有记录但句柄是空的 | 换一个已有句柄的 Agent |
| 签名被拒，这一张没有送出 | 没有交易 | 不用重试这笔拒绝 |
| 气费不够，交易没有出门 | BNB 不够气费和价款 | 在 App 里自备 BNB |
| 铸额用尽 | 剩余铸额小于这一笔 | 走池子。卖回不恢复铸额 |
| 曲线余额不足 | 卖出多于手里的币或曲线供给 | 把枚数改小，或先铸 |
| 尚无赎回 | 曲线上还没有可卖回的币 | 先铸。不要把池价当成赎回价 |
| 无池价 | 池子一侧储备为 0 | 先点「入」 |
| 连不上节点 | 没有新的读数 | 恢复后再核对剩余铸额，不要凭失败再提交 |
| 链上把这笔退回了 | 合约回滚 | 改数量或换动作。不要连着提交第二次 |
| 送出途中网络断了 | 没有拿到回执 | 先核对铸额和余额，变过就不要再提交 |

产品页面不会代为送出。确认在币安 App 里。开发演练才由 `script/rehearse-local.sh` 在回环上执行，那不是 `script/serve-curve.sh`。
